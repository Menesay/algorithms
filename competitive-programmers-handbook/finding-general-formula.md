
# finding genral formula of
8 , 24, 48, 80

```
╔══════════════════════════════════════════════════════════════╗
║           FINITE DIFFERENCES TECHNIQUE                       ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║  SEQUENCE:  8,  24,  48,  80, ...                            ║
║                                                              ║
║  STEP 1 — TAKE DIFFERENCES                                   ║
║                                                              ║
║   a(n):   8    24    48    80                                ║
║            \   /  \   /  \   /                               ║
║   Δ¹:      16    24    32                                    ║
║              \   /  \   /                                    ║
║   Δ²:          8     8      ← CONSTANT                       ║
║                                                              ║
║  Constant at level 2  →  formula is DEGREE 2 (quadratic)     ║
║                                                              ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║  STEP 2 — ASSUME  a(n) = An² + Bn + C                        ║
║                                                              ║
║   a(1) =  8   →   A +  B + C =  8                            ║
║   a(2) = 24   →  4A + 2B + C = 24                            ║
║   a(3) = 48   →  9A + 3B + C = 48                            ║
║                                                              ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║  STEP 3 — SOLVE THE SYSTEM                                   ║
║                                                              ║
║   eq2 - eq1  →  3A +  B = 16                                 ║
║   eq3 - eq2  →  5A +  B = 24                                 ║
║   subtract   →  2A     =  8  →  A = 4                        ║
║                              →  B = 4                        ║
║                              →  C = 0                        ║
║                                                              ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║  RESULT:  a(n) = 4n² + 4n = 4n(n+1)                          ║
║                                                              ║
║   n=1:  4·1·2 =  8  ✓                                        ║
║   n=2:  4·2·3 = 24  ✓                                        ║
║   n=3:  4·3·4 = 48  ✓                                        ║
║   n=4:  4·4·5 = 80  ✓                                        ║
║                                                              ║
╠══════════════════════════════════════════════════════════════╣
║  RULE:  constant at Δᵏ  →  degree-k polynomial               ║
║         then plug in k+1 points and solve the system         ║
╚══════════════════════════════════════════════════════════════╝
```
